# Images Folder

Place your images here:

## Required Images:

### Logos:
- `logo.png` - Main logo (for intro page, white/light background)
- `logo-white.png` - White logo (for navbar, dark background)

### City Images:
- `mumbai.jpg` - Mumbai city image
- `delhi.jpg` - Delhi city image
- `bangalore.jpg` - Bangalore city image
- `pune.jpg` - Pune city image

### Hostel Images:
- `hostel1.jpg` through `hostel6.jpg` - Individual hostel images
- Or use hostel-specific names

### Other:
- `about-banner.jpg` - Banner for about page
- `qr-code.png` - Sample QR code for payments

## Image Specifications:
- Logos: PNG format, transparent background recommended
- City images: 800x600px minimum
- Hostel images: 1200x800px minimum
- QR code: 500x500px

## Temporary Placeholders:
The website uses gradient backgrounds and emoji icons as placeholders until you add real images.
